# Преподаватели и мастера

Страница: **/staff** (админка → «👩‍🏫 Преподаватели и мастера»). Только администратор.

## Как считается

| | Преподаватели (группа «Преподаватели») | Мастера (группа «Мастера») |
|---|---|---|
| Основа | расписание Kundoluk: первый и последний урок дня | рабочий день пн–пт (сб, если у группы «Мастера» учебная суббота) |
| Опоздание | вход по СКУД позже начала первого урока (+ `TEACHER_LATE_GRACE` мин) | не считается |
| Ранний уход | последний выход раньше конца последнего урока | не считается |
| Часы | от первого входа до последнего выхода | так же |
| Не пришёл | нет входа в день, когда есть уроки | нет входа в рабочий день |
| Нет уроков | день не считается нарушением | — |
| Уведомления | админу в Telegram: неявка (через 10 мин после начала первого урока) и опоздание — по разу в день; итог дня в 18:30 | только в итоге дня |

Причину отсутствия (болезнь, командировка) ставит админ кнопкой «Причина» — день не считается нарушением.

## Откуда расписание

1. **Редактор расписания** (Schedule_ekundoluk): кнопка «📤 pl3service» — отправка опубликованной недели,
   можно автоматически после публикации. На сервере нужна переменная `SCHEDULE_API_KEY`, в редакторе — тот же ключ.
   Приём: `POST /api/agent/teacher-schedule`, заголовок `X-Api-Key`.
2. **Excel из «Отчётов» редактора** — вкладка «Расписание» на /staff.

Повторная отправка той же недели группы заменяет её, а не дублирует. ФИО сопоставляются с сотрудниками СКУД
по фамилии и инициалам («Иванова Айгуль Асановна» = «Иванова А.А.»); если не нашлось — сопоставьте вручную
во вкладке «Расписание», это запоминается.

## Табель

Вкладка «Табель» → «📥 Табель в Excel»: листы «Преподаватели» (приход, +мин опоздания, ↑мин раннего ухода, Н, У,
итоги) и «Мастера» (часы, Н, У, итоги).
