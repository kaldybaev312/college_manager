Временная ссылка-анкета

Сотрудник сам вводит ФИО, ИНН и добавляет фото. Поименный номер выдаётся автоматически после вашего одобрения. Для гостей по умолчанию пропуск на 30 дней, потом он перестаёт действовать сам; для остальных можно указать срок в днях.

Массовая загрузка из Excel

Столбцы как при загрузке студентов: ФИО, дата рождения, ИНН, номер (номер необязательно, без него выдаётся автоматически). Первой строкой могут быть заголовки. Можно только ФИО и ИНН. Скачать шаблон

После загрузки сотрудникам нужно добавить фото: страница «Регистрация студентов», выбрать группу (Преподаватели, Мастера, Администрация). Фото можно загрузить по одному, массово (имя файла = номер или ИНН) или отправить сотруднику ссылку с QR.
